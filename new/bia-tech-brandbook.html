Identidade

Fundamentos da marca BIA Tech — o que é, para quem existe, e os princípios que guiam cada decisão de design e experiência.

O que é BIA Tech

Não é uma ferramenta. É uma camada de inteligência integrada ao jeito que o Bradesco desenvolve software — presente nos momentos certos, invisível quando não é necessária, e cada vez mais capaz conforme os times a utilizam. A BIA Tech é a aposta do Bradesco de que o futuro da engenharia de software não é substituir pessoas por IA — é dar às pessoas as melhores condições para construir o que só elas sabem construir.

Cada ferramenta existe para um único objetivo: reduzir o esforço repetitivo e aumentar a velocidade e qualidade de entrega dos times de engenharia.

Missão
Fazer os times de tecnologia do Bradesco entregarem mais, com menos esforço — e sem abrir mão da qualidade.
Princípios de design
01
Técnica
A plataforma fala a linguagem dos desenvolvedores. Densa onde precisa ser, simples onde pode ser.
02
Confiável
Respostas consistentes, rastreáveis e auditáveis. O desenvolvedor precisa confiar no output da IA para agir sobre ele sem hesitação.
03
Aceleradora
Cada interação poupa tempo real. A plataforma nunca adiciona fricção ao fluxo de trabalho — só reduz. Se não acelera, não pertence à interface.
04
Integrada
Parte natural do pipeline de desenvolvimento, não um desvio. A BIA Tech aparece onde o desenvolvedor já está trabalhando, não onde ele precisaria ir.

Espaçamento

Grid base de 4px. Todos os espaçamentos derivam deste múltiplo — garantindo consistência e previsibilidade entre componentes e layouts.

--space-6 24px
Gap entre grupos de elementos
--space-8 32px
Margem entre subseções
--space-10 40px
Padding de cards grandes
--space-12 48px
Padding de seções em mobile
--space-16 64px
Espaço entre seções principais
--space-20 80px
Padding lateral do layout desktop
Regra
Use sempre múltiplos de 4px
Valores como 5px, 7px, 13px quebram o grid e criam inconsistência visual entre componentes.
Tokens, não valores absolutos
Use os tokens CSS (--space-4, --space-6…) nos componentes — nunca valores hardcoded. Facilita ajustes globais de densidade.

Todo elemento que recebe foco via teclado deve exibir o anel visível. Nunca use outline: none sem fornecer um substituto visual equivalente.

Outras regras
Área clicável mínima
44 × 44px
Botões, ícones clicáveis e itens de navegação devem ter área de toque mínima de 44×44px — mesmo que visualmente menores. Use padding para expandir a área.
Não use cor como única informação
ícone + cor + texto
Status, erros e alertas devem combinar cor com ícone ou texto. Um usuário daltônico não pode depender apenas do vermelho/verde para entender o estado.
Labels em todos os inputs
aria-label ou <label for>
Placeholder não substitui label. Todo campo de formulário precisa de label associado — visível ou via aria-label para leitores de tela.
Tamanho mínimo de texto
12px mínimo · 14px recomendado
Texto abaixo de 12px não é legível e não passa em auditorias de acessibilidade. Use 11px apenas para metadados decorativos não informativos.

Uso correto

Diretrizes para manter a consistência da marca em todas as aplicações.

FAÇA
Use o wordmark completo com o descritivo
Respeite a zona de proteção do logo
Use cyan exclusivamente para IA e interações
Use JetBrains Mono em contextos técnicos
Mantenha o pipe entre BIA e Tech
Use badges mono em fundo escuro para status técnicos
Use vermelho Bradesco como cor de ação primária
NÃO FAÇA
Não use o logo sem o descritivo em contextos formais
Não altere as proporções do wordmark
Não use cyan como cor primária de CTAs
Não use Inter em blocos de código ou terminais
Não remova o pipe do wordmark
Não use mais de 2 cores de destaque por tela
Não aplique o logo sobre fundos com pouco contraste
